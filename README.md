# Sassonia — Family Hub

Home Assistant Add-on for managing family recipes, shopping list, and tasks.

## Features
- Recipe book with image scanning (Google Gemini AI)
- Dynamic shopping list with bulk import from recipes
- Tasks / to-do list
- PWA — installable on phone home screen
- Hebrew & English UI

## Installation

1. In Home Assistant, go to **Settings → Add-ons → Add-on Store**
2. Click the 3-dot menu (top right) → **Repositories**
3. Add: `https://github.com/sasson123/Sassonia`
4. Find **Sassonia** in the store and click **Install**
5. In the add-on configuration, enter your **Gemini API Key**
6. Start the add-on

Access at: `http://your-ha-ip:8099`
